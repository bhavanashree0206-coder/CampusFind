CampusFind - College Lost & Found Portal
CampusFind is a centralized campus utility web application that streamlines the process of reporting, searching for, and recovering misplaced belongings for college students and staff.

🚀 Features
Dual-Type Reporting: Easily submit reports for both lost items and found belongings with category tagging, location descriptors, and image attachments.

Advanced Search & Filtering: Filter live feeds dynamically by item category, report type (Lost vs. Found), active status, and search keywords.

Secure Claim Verification: Ownership claim workflow requiring confidential proof features to prevent fraudulent collection.

Admin Control Panel: Switch to Admin View to review user-submitted bug/scam reports, mark items as returned, and manage listings.

🛠️ Tech Stack
Frontend Structure: HTML5, Tailwind CSS

Icons: FontAwesome

Logic: Vanilla JavaScript (ES6+)

Persistence: Browser LocalStorage

~Getting Started in VS Code
Clone or download this repository.

Open the project folder in Visual Studio Code.

Install the Live Server extension.

Right-click index.html and select Open with Live Server.
